# Foon Yul Xin Portfolio Update

## Files
- `index.html` — complete portfolio page
- `assets/` — profile portrait and project screenshots
- `Foon-Yul-Xin-CV.pdf` — CV used by the download button

## Publish to GitHub Pages
1. Extract this ZIP.
2. Open your `foonyx.github.io` repository on GitHub.
3. Upload/replace `index.html`, the `assets` folder, and `Foon-Yul-Xin-CV.pdf` in the repository root.
4. Keep the `assets` folder structure intact; the HTML references images inside it.
5. Commit the changes, then refresh your portfolio after GitHub Pages finishes deploying.

The internship date was not listed in the CV, so the timeline labels it as “Date not listed.” Check that the CV filename matches exactly.
